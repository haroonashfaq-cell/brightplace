# Ranking Rules (Editorial Targets)

Migrated: 2026-09-16. Sources: Claude project `MEMORY.md`, Ranking Optimization
Rules (August 2026); `Agents/WORKFLOW.md` Stage 3; `Agents/qa-agent.md` §2B.
These are editorial targets, not guarantees of ranking or causal research findings.

1. Use question-format H2s aligned with relevant PAA/search questions.
2. Repeat primary entities naturally (3–8 mentions; key locations 3–5), without
   stuffing. Exact-keyword guidance is separate: 7–12 uses in a 1,200–1,500-word
   article, never more than 1.5%. Prefer readable wording over forced repetition.
3. Target 10+ useful FAQ answers for Resources articles, minimum 6–8 if justified
   in the brief; answers 40–60 words. Renter's Corner retains its own 4–6 / 40–80 rules.
4. First paragraph after H1: 49–55 words, primary keyword, self-contained direct answer.
5. At least 7 relevant, verified internal content links; use the length-based target
   in content-standards.md for longer articles. CTAs are counted separately.
6. Match article/guide search intent; see keyword-strategy.md.
7. Fill real gaps with sourced data, useful comparisons, and honest tradeoffs.

Conflict resolution: the canonical targets here replace old 8+ entity and fixed
6–8 FAQ limits in generic prompts. These numerical targets must not be presented
as externally proven algorithm thresholds. The old "3x snippet capture" claim is
unverified and is not retained as evidence.
